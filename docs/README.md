# SW Mercs Industry – Project knowledge base

This directory preserves design decisions and project data independently of chat history. JSON files here are reference documents, not automatically loaded application configuration.

- `GALACTIC_RULES.json`: travel, communications, zone concept.
- `ECONOMIC_MODEL.json`: original economic model.
- `CSA_Sector-Systems.json`: original V7 sector dataset (59 systems).
- `GOODS_MASTER.json`: index of existing authoritative data under `/data`.
- `STARSHIP_MASTER.json`: index of the recovered [ship, station and container enum](../data/ships/starship_master_enum.json).
- [STARSHIP_CATALOG.md](STARSHIP_CATALOG.md): editor workflow and per-class JSON format.
- `EVENT_MODEL.json`: recovered design notes; not a complete executable schema.

For editor implementation see [README](../README.md), [architecture](ARCHITECTURE.md), and [historical project summary](archive/PROJECT_SUMMARY.md). Do not treat incomplete records as final rules or delete original chats until their contents have been reconciled.
