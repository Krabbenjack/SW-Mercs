# Legacy Star Map Editor entry point

The application now starts from the [repository root](../README.md) using `swmercs.bat` or `python swmercs.py`.

For compatibility, `python star-map-editor/main.py` still starts the map editor directly. The actual implementation is in `app/editors/starmap/`. The previous documentation is preserved in [docs/archive/starmap](../docs/archive/starmap/README.md).

Existing local map saves are not moved or deleted.
